# `GDAB2e-py`: Python Companion to _Genetic Data Analysis for Breeding_ (2nd Editiion) by Fikret Isik, James Holland, Christian Maltecca

This is intended to be a Python companion to [Isik, F, et al; _Genetic Data Analysis for Breeding_ (2nd Editiion); 2025+](https://faculty.cnr.ncsu.edu/fikretisik/second-edition-genetic-data-analysis-for-animal-and-plant-breeding/), which employs _ASReml_ and _ASReml-R_ as the original computational framework.
